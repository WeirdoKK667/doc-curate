## 标签清单

| 标签 | 含义 | 必填 |
|---|---|---|
| `<!-- page:N -->` | 页起始（N = PDF 物理页号） | ✅ |
| `<!-- 印刷页码：xx -->` | 印刷页码（= 物理页 + offset） | 推荐 |
| `## 【PDF 第 N 页】` | 页标题（KEEP_MARK=on 时） | KEEP_MARK=on |
| `<!-- /page -->` | 页结束 | ✅ |
| `<!-- IMAGE:pN_imgNN.png -->` | 图片起始 | 按需 |
| `<!-- /IMAGE -->` | 图片结束 | 按需 |
| `<!-- TABLE:pN_tNN -->` | 表格起始 | 按需 |
| `<!-- /TABLE -->` | 表格结束 | 按需 |
| `<!-- footnote:N -->` | 脚注起始（N = 编号） | 按需 |
| `<!-- /footnote -->` | 脚注结束 | 按需 |
| `<!-- para:N -->` | 中英对照段落（BILINGUAL=on） | BILINGUAL=on |
| `<!-- /para -->` | 中英对照段落结束 | BILINGUAL=on |
| `<!-- tag:xxx -->` | 内容标签 | 按需 |
| `<!-- /tag:xxx -->` | 内容标签结束 | 按需 |

## IMAGE 标签详细

```markdown
<!-- IMAGE:p323_img01.png -->
图题原文：Figure 3-1. ...

图题译文：图 3-1 ...

图中文字译文：
- 横轴刻度标签：...
- 左上角标注框：...
- 图例第 2 项：...
<!-- /IMAGE -->
```

规则：
- 图题原文 / 译文 必填
- 图中文字译文按位置列点
- IMG_DEPTH=caption 时只译图题，跳过图中文字

---

## TABLE 标签详细

```markdown
<!-- TABLE:p323_t01 -->
表题原文：Table 3-1. ...

表题译文：表 3-1 ...

| 列 1 | 列 2 | 列 3 |
|---|---|---|
| 值 1 | 值 2 | 值 3 |
<!-- /TABLE -->
```

规则：
- 表题原文 / 译文 必填
- markdown 表格完整（表头 + 内容均译）
- 数字 / 单位保留原样
- 脚注式 `a/b/c` 标记保留

## 存疑标记

格式：`[?第N页-第K段-原文短语]`

```markdown
正文译文...

地质构造 [?第326页-第3段-"syntaxial growth"] 影响了...
```

写入 `ISSUES.md`（含定位信息）。

---

## 中英对照（BILINGUAL=on）

```markdown
<!-- para:1 -->
原文：The geological structure of Mt Elgon is...

译文："Mt Elgon" 的地质构造是...
<!-- /para -->
```

规则：
- 原文与译文段号 1:1 对齐
- 缺失段标 `[?段落缺失]`
- 优先按段落对照，段落过长才按句

---

## 校验

阶段 5 解析 zh.md 时按以下规则校验：
1. 每个 `<!-- page:N -->` 必有匹配的 `<!-- /page -->`
2. IMAGE / TABLE 标签与文件存在一一对应
3. 段落 1:1 对齐（与原文段落数对比）
4. 页数 = PAGE_END - PAGE_START + 1
