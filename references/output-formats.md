# output-formats.md · 输出版式细则

> 阶段 5 导出产物的版式规范。

---

## 一、md 模块化（OUTPUTS 含 md）

### 三种形式

| 形式 | 适用 | 标签结构 |
|---|---|---|
| **自然结构** | 普通情况 | `# / ## / ###` 标准 markdown |
| **按页分割** | PDF 等需标注页码 | `## 【PDF 第 N 页】` + `<!-- page:N -->` |
| **按内容标签** | 检索场景 | `<!-- tag:xxx -->` 块包围 |

详见：`assets/md-template.md`

### 章节标题自动识别

| 模式 | Heading |
|---|---|
| `12` / `12.1` / `12.1.1` | H1 / H2 / H3 |
| `Chapter 12` / `Section 12.1` | H1 / H2 |
| `第 12 章` / `12.1 节` | H1 / H2 |

### 标签注册

内置保留标签（6 类）：
- `<!-- tag:chapter -->` 章节级
- `<!-- tag:section -->` 小节级
- `<!-- tag:figure -->` 图片相关
- `<!-- tag:table -->` 表格相关
- `<!-- tag:footnote -->` 脚注相关
- `<!-- tag:citation -->` 引文相关

用户自定义标签需在 PARAMS 中声明 `CUSTOM_TAGS: [...]`

## 二、Word 成稿（OUTPUTS 含 word）

### 字体硬约束

| 元素 | 中文字体 | 西文字体 |
|---|---|---|
| 正文 | 宋体 | Times New Roman |
| 标题 | 黑体 | Times New Roman |
| 等宽 | 宋体 | Courier New |

**必须同时设 `font.name`（西文）+ `font.element.rPr.rFonts.eastAsia`（中文）**，否则中文不渲染。

### 版式

| 项 | 规则 |
|---|---|
| 行距 | 1.5 倍 |
| 首行缩进 | 2 字符 |
| PDF 页码标记 | **红色小字**插入正文对应位置 |
| 正文 | 优先贴合原格式，其次考虑默认报告格式 |
| 多级标题 | 贴合原格式；样式：黑体 + 深蓝色 |
| 图名 | 居中：图 N-X 中文译名（原文图名） |
| 表名 | 表格上方 |
| 公式 | 独立居中 |
| 图片 | 居中，超宽等比缩放到 15cm |

### 页标记（KEEP_MARK）

| KEEP_MARK | 处理 |
|---|---|
| `on` | 每页起始 `【PDF 第 N 页】`，**Normal 段 + 加粗 + 浅灰底**（避免污染 Word 导航窗格） |
| `off` | 不输出页标记 |

### [?] 存疑版式
含 `[?]` 的正文段**自动拆为两段**：
- 去 `[?]` 的正段（正常样式）
- 浅灰小一号"注：…"子段（保留原文 + 存疑说明）

### 装饰图回插
`images_ignored/` 中的装饰图**按原 PDF 页位置回插正文末**，标"疑似装饰性图片"。

### 附录 A 三档分列

```markdown
## 附录 A
### A.1 装饰性图片
### A.2 范围内未引用图
### A.3 范围外参考图
```

### 脚注

| FOOTNOTE | 处理 |
|---|---|
| `docx` | 转 Word 真实脚注 |
| `inline` | 段内 `[N]` 编号 |

### 表格

| TABLE_MODE | 处理 |
|---|---|
| `native` | Word 原生表格（表头保留、表题在表上方、保留边框） |
| `image` | 截图嵌入 |

### 卷首
```markdown
# 文献标题（中译 + 原文）

原文页码范围：PDF 第 {{PAGE_START}}-{{PAGE_END}} 页

## 翻译说明
- 专有名词规则
- 图片文字处理方式
- 存疑项数量
```

### 兜底补入
manifest 标 `reused_in_pages` 但首屏未插入的图 → 自动在尾页兜底插入并标注页码。

## 三、目录 docx（可选）

### 生成
- 阶段 5 跑 `scripts/build_toc_docx.py`
- 仅章节标题 + PDF 页标记
- 输出独立小 docx

### 用途
- 便于导航
- 校对时定位章节

---

## 四、两版输出策略

### 默认
skill 默认输出 **两版**：
- **校对稿**：`KEEP_MARK=on`，便于校对定位
- **正式稿**：`KEEP_MARK=off`，干净成稿

### 命名
```
<动作><格式>：<源文件名>_<校对稿/正式稿>_P<起>-<止>.docx
<动作><格式>：<源文件名>_<校对稿/正式稿>.md
```

## 五、用户指定的其他产物

### 接入方式
- PARAMS `OUTPUTS` 列表中加新格式（如 `pptx, html`）
- 阶段 5 按列表依次生成
- agent 判断有更好形式可询问用户

### 配套脚本
- `scripts/build_<format>.py`
- 详见：`scripts/build_*.py` 实际接口

---

## 六、产物组装走脚本（硬约束）

**禁止 agent 硬堆产物**——所有组装工作统一调用 `scripts/build_*.py`。

### 理由
- 标准化版式
- 可重复运行
- 减小 agent token 消耗
- 完整性断言可在脚本中实现
